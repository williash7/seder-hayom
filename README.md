# סדר היום

האפליקציה שמלווה את אשר לאורך כל היום — מההשכמה ועד קריאת שמע שעל המיטה.
היום בנוי כשרשרת **תחנות**. מסך "עכשיו" מראה רק את התחנה הנוכחית, ואת
העוגן הקבוע הבא (כולל, איסוף, מניין) — והאם מספיקים אליו.

## התקנה בטלפון

כל דחיפה ל-`main` בונה APK תוך כ-10 דקות (לשונית **Actions**).
הקובץ מתפרסם ב-**Releases** — פותחים מהטלפון ומתקינים.

סודות החתימה (Settings ← Secrets ← Actions):
`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.
**לשמור את קובץ הסודות** — בלי המפתח אי אפשר לעדכן את האפליקציה המותקנת.

## איך זה בנוי

| קובץ | מה יש בו |
|---|---|
| `lib/defaults.js` | התחנות, המקומות, המניינים — סדר היום עצמו |
| `lib/engine.js` | המנוע: שעות לכל תחנה, תחנות "ממלאות", עוגנים, בחירת מניין |
| `lib/DayContext.js` | מצב היום והפעולות (בוצע, דלג, קפוץ, בחירת מניין) |
| `lib/notify.js` | שעון מעורר, תזכורות לעוגנים, סגירת יום |
| `stations/Stations.js` | המסך של כל סוג תחנה |
| `screens/` | עכשיו · היום · הגדרות |

**עוגן** = שעה שלא זזה (`at`, `arriveBy`, מניין, הדלקת נרות).
**תחנה ממלאת** (`fill`) = תופסת את כל הזמן שנשאר עד העוגן הבא — למשל
הלימוד לפני שחרית מתארך או מתקצר לפי המניין שנבחר.

בדיקות המנוע: `npm run check` (רצות גם בכל בנייה).

## מודול אנדרואיד (`modules/seder-native`)

| קובץ | מה הוא עושה |
|---|---|
| `AlarmScheduler.kt`, `AlarmReceiver.kt`, `AlarmActivity.kt` | שעון מעורר אמיתי: `setAlarmClock`, התראה על מסך מלא שמצלצלת עד שלוחצים, מסך "קמתי / עוד 5 דקות" |
| `BootReceiver.kt` | מחזיר את השעון אחרי הפעלה מחדש |
| `HomeLockService.kt`, `LockState.kt` | שירות נגישות: בזמן בית מחזיר לסדר היום כשנפתחת אפליקציה שלא אושרה |
| `UsageLog.kt` | יומן מעברים בין אפליקציות → כמה זמן בכל אחת |

נעילה ויומן נשמרים רק בטלפון. זיהוי הגעה — `lib/geo.js` (גדר וירטואלית של expo-location).

## מה עוד לא נבנה

- עדכונים מיידיים (OTA) בלי להתקין APK מחדש — מחכה לסוד `EXPO_TOKEN`
